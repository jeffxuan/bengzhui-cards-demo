# 临时效果清单

新版文档中存在引用但未在当前规则数据中定义的名词。开发阶段允许按上下文建立临时别名，但不得伪装成已冻结规则。

## 实施政策

1. 能明确映射到现有效果时，使用 `rules/effect_aliases.json` 记录映射。
2. 无法完全映射时，保留牌面意图，使用最小可玩实现，并将 `provisional: true` 写入内容数据。
3. provisional 效果必须生成调试事件，记录来源文档、临时语义和触发次数。
4. provisional 效果不能阻止保存、回放或继续对局；但内容校验器必须在 CI 中输出清单。
5. 首发公开版本前，所有 provisional 项必须转为正式语义或从启用池移除。
