# 《崩坠牌局》0.1.0-dev.6 试玩说明

## 启动

- Windows：解压 `BengzhuiCards-Windows-0.1.0-dev.6.zip`，双击 `BengzhuiCards.exe`。
- macOS：解压 `BengzhuiCards-macOS-0.1.0-dev.6.zip`，双击应用；如果系统阻止启动，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

本版本默认是一名玩家对三名 AI。首次进入后选择角色即可开始；目标是成为最后一名存活者。棋盘只在发生淘汰后从 15×15 崩坠到 11×11，再到 7×7。

## 操作提示

- 鼠标点击高亮格移动或选择目标；键盘可用 Tab、方向键、Enter 和 Escape 完成主要操作。
- 选择卡牌或技能后，棋盘会显示方形（切比雪夫）范围和合法目标。
- 回合开始可以保持主职业或切换副职业；转换只影响抽牌来源和本回合抽牌数量，角色技能不变。
- 商店购买的普通牌会跨回合保留，直到打出；装备牌打出后进入装备槽。
- 手牌超过上限时，必须在弃牌面板中选择要弃置的牌。

## 反馈方式

遇到问题时，请在反馈中附上：

1. 版本号和操作系统；
2. 调试信息面板中的规则版本、内容版本、种子、阵容、胜因和命令数；
3. 触发问题前的操作、预期结果、实际结果和复现频率；
4. 截图或录屏（如有）。

## 已知限制

- 这是公开试玩开发版，部分复杂牌面和角色流程仍会显示 `provisional` 标记。
- macOS 包未签名；Windows 构建需要在真实 Windows 环境中完成最后的整局验证。
- 目前不包含联网、账号、付费或遥测上传。
