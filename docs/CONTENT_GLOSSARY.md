# 新版内容术语表

## 牌面术语

- **类别**：攻击、防御、奇异、装备；类别用于目标、响应和事件判断。
- **花色**：黑桃、红桃、梅花、方块。花色是牌副本的稳定属性。
- **点数**：A、2-10、J、Q、K。点数用于比较、求和和角色技能条件。
- **颜色**：红色包含红桃/方块，黑色包含黑桃/梅花；颜色只在牌面明确要求时使用。
- **独立副本**：同名牌的不同花色/点数副本，各自拥有不可重复的实例 ID。
- **耐久**：装备剩余可用次数；“无限”用 `null` 表示，不用魔法数字。

## 棋盘术语

- **方形范围**：以角色为中心的正方形区域，切比雪夫距离不超过指定半径。
- **正交路径**：每一步只能上下左右移动，不允许斜向移动。
- **神异格**：停留时抽取一张公共事件牌，结算后变为普通格。
- **攀升阶段**：崩坠后执行重铸、奖励和回到合法区域等结算。

## 状态与限制

- **限一次/限两次**：严格按对应技能或牌面的时间窗口执行。
- **回合限次**：从角色开始回合到其结束回合计算。
- **本轮限次**：从本轮第一名角色开始行动到全员行动结束计算。
- **provisional**：效果已有临时实现，但语义仍需用户或设计复核；必须在调试信息和内容清单中可见。

## 角色范围

当前首发角色：Q、K、Shya、Ginger、Z&C、Na1、Maddy、Signal。

文档中的 W、QiQi、胖大海、Thunderous.F、Yellow.H、Chao.Y、BY、Cobalt 及其他角色均暂不进入首发对局。
