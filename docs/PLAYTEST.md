# 试玩反馈指南

## 测试顺序

1. 先进行 12 人封闭测试，确认规则理解、操作阻塞、对局时长与崩溃问题。
2. P0/P1 问题清零后进行至少 30 人公开测试。
3. 每轮测试使用固定构建版本汇总数据，禁止混合不同规则版本计算胜率。

## 每局记录

- 游戏版本、操作系统与屏幕分辨率。
- 调试信息面板中的规则版本、内容版本、种子、阵容、胜因和命令数。
- 实际对局时长、胜者、结束轮数与是否理解决胜阶段。
- 问题发生前的操作、预期结果、实际结果及复现频率。
- 可用时附截图和 `user://resume_match.json`；不得包含与问题无关的个人信息。

目标平均时长为 10-14 分钟，95% 对局位于 6-18 分钟。P0 表示无法启动、存档损坏或稳定崩溃；P1 表示无法继续对局、错误胜负或可稳定利用的非法行动。
