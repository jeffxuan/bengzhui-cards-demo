# 新版规则差异清单

版本：draft-new-rules-2026-08-27

## 权威来源

本轮以用户提供的 `GAME规则(1).docx`、`GAME角色.docx`、`GAME卡牌.docx` 和 `GAME事件.docx` 为新版内容源。它们优先于仓库 v5 及更早规则；发生冲突时，以用户后续确认和本清单记录的新版裁决为准。

## 已冻结裁决

| 主题 | v5 及早期基线 | v6 裁决 |
| --- | --- | --- |
| 首发角色 | 8 名 | 仍只启用 Q、K、Shya、Ginger、Z&C、Na1、Maddy、Signal |
| 牌库 | 80 张、部分新版牌晋升 | 正常对局只使用文档中的通用牌、7 个职业牌库和装备牌；旧牌不进入牌堆 |
| 花色/点数 | 无实例级字段 | 每张副本记录独立花色、点数和实例 ID |
| 行动点 | 出牌/技能/购买共享行动点 | 移除行动点对出牌和技能的限制；商店改由独立购买次数控制 |
| 范围 | 曼哈顿距离 | 3x3、5x5、7x7 采用方形切比雪夫范围 |
| 移动 | 最多 3 格 | 按新版方形移动范围选择正交路径，具体数值由角色/装备规则决定 |
| 技能次数 | 旧实现曾有统一每回合限制 | 只执行技能文本明确写出的限次；未写限次可重复 |
| 弃牌 | v4 已有回合结束弃牌 | 恢复卡牌、技能和事件中的主动/强制弃牌效果 |
| 装备 | 旧装备字段较少 | 武器/防具使用消耗 1 体力，饰品消耗 1 法力；增加耐久、替换、额外装备栏和过载 |
| 事件 | 16 张分类事件 | 全量导入新版事件；抽后弃置，牌堆耗尽后洗回 |

## 暂不改变的运行边界

- 仍为单人对三名 AI。
- 仍使用确定性种子、命令日志和规则层事件。
- 新角色先只进入数据结构，不进入首发阵容。
- 首发发布前，所有 `provisional` 效果必须完成复核或明确标注。
