# 新版内容导入状态

- 内容目录支持逻辑 `card_id` 与独立 `instance_id`（例如 `slash#001`）双层查找。
- 卡牌元数据字段已纳入目录校验：`suit`、`rank`、`color`、`durability`、`copies`、`provisional`。
- 旧版 80 张逻辑牌仅保留给迁移与定向测试，已从初始手牌、通用/职业牌堆和市场移除。
- `provisional` 效果和别名表可以被校验并输出报告。
- 已保留新版原始 DOCX 与提取文本于 `docs/source/`（该目录不进入公开仓库）。
- 已导入新版暂存内容：8 名首发角色、165 个逻辑卡牌定义、611 个花色/点数副本及 27 个事件定义。
- 运行时已优先采用新版角色的主/副职业与生命、体力、法力基础值；现有技能执行继续通过兼容层运行，待新版技能逐名替换。
- 新版文档中明示的角色技能限次已通过兼容映射进入规则层：K「巨脑」、Maddy 两个主动技能与 Signal「制频」每回合限 1 次，K「奇策」本局每职业限 1 次；未写限次的技能仍可重复使用。
- 通用牌库与 7 个职业牌库均可按职业、花色、颜色和点数查询；同一逻辑牌的副本使用稳定 `card_id#序号` 标识。
- Q 的暂存技能“雷暴”已接入可执行的点数和弃牌流程，其他未冻结语义仍明确保留 `provisional` 标记。
- 全部 165 个新版逻辑牌定义和 611 个花色/点数副本已进入开发牌池；未完成的复杂效果仍会发出 `provisional` 反馈。
- 初始手牌、通用牌堆、当前职业牌堆和市场全部使用新版副本 ID；牌堆在种子控制下洗牌，不再按同名牌成组抽取。
- 新版装备进入运行时时获得明确使用费用：武器/防具 1 体力，饰品 1 法力；费用已由合法性检查、支付和 UI 共用。
- K「奇策」已标记为能力技并建立耗尽数据；Ginger「强攻」已标记为突破技，并结构化「回合内回复 3 生命或击杀 2 人」的破围目标。完整效果执行仍保持 `provisional`。
- 调试信息中的“暂存牌：可映射”统计的是效果序列中不含 `op: provisional` 的卡牌数量；它仅说明当前通用效果组合器能够表达该序列，不代表该牌已经完成规则复核、目标规则配置或平衡验证。

## 尚未完成的正式语义

新版数据已替换正常抽牌路径，但复杂卡牌、装备耐久和角色技能仍有 `provisional` 语义。该标记必须对玩家和调试信息可见。

以下内容仍需完成后才可解除 `provisional` 标记：

- 将全部可由通用效果组合器表达的暂存卡牌转为正式可执行效果；
- 实现装备耐久、复杂弃牌、延迟效果、位移、条件伤害及事件专属逻辑；
- 为每张 provisional 内容建立确定性规则测试；
- 完成新版数据池的 AI 模拟与人工试玩平衡验证。

不得使用猜测内容填充未定义字段。无法从文档确定的效果必须继续使用 `provisional` 并登记到 `docs/PROVISIONAL_EFFECTS.md`。
