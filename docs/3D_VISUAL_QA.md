# 3D 棋盘视觉验收提示词

将下面的提示词连同同一局对战在 1280×720、1920×1080、2560×1440 下的截图、一次移动录屏和一次命中录屏交给评审。先独立观察画面，再对照事件日志；不要因为知道设计意图而替画面解释。

> 你是《崩坠牌局》的视觉与交互评审。它是 15×15 方格策略卡牌游戏，不是自由移动动作游戏。请逐项指出玩家在三秒内能否辨认四名角色、当前行动者、可移动格、攻击范围、合法目标、危险格和本次伤害结果。检查模型、灯光、镜头与特效是否帮助判断局势。不得把“更立体”直接当作“更好看”；如果装饰遮挡格线、角色或目标，判为失败。请给每项 0–5 分、指出截图坐标或录屏时间，并写出最小的可执行修改。

评分项及最低门槛：

| 项目 | 5 分标准 | 通过门槛 |
|---|---|---|
| 棋盘辨认 | 15×15 边界、崩坠区、财富/事件/陷阱格在一眼内可分辨；格子可数 | ≥4 |
| 角色辨认 | 四个单位轮廓、归属、生命和选中状态无需悬停即可区分 | ≥4 |
| 操作可靠 | 鼠标和键盘指向同一逻辑格；合法目标与普通射程格不同 | 5 |
| 命中反馈 | 出手、受击、护甲抵消、击败的视觉与音效不同；150–250ms 后不遮挡操作 | ≥4 |
| 画面质感 | 模型比例、材质、光影一致；没有未贴图或悬空模型 | ≥4 |
| 可访问性 | 减少动态效果时仍能读出结果；色彩不是唯一信号 | 5 |
| 性能与稳定 | 三档分辨率无空白帧、重叠、未处理错误，实际对局无明显掉帧 | 5 |

总分低于 29/35，或任何强制项未达标，都不替换公开试玩版的默认棋盘。每次修订记录截图、种子、Godot 版本、资产版本和重新评分。真人试玩反馈优先于自评分。
