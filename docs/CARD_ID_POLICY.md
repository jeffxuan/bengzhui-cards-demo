# 卡牌实例 ID 规范

## 目标

花色和点数会参与技能、事件、弃牌、复制和回放。逻辑同名牌不能再共用一个可变身份。

## 双层标识

- `card_id`：逻辑牌名，例如 `slash`、`crossfire`。
- `instance_id`：副本稳定 ID，例如 `slash_spade_a`、`slash_heart_2`。

内容定义中每个副本使用一个对象；对象必须包含 `card_id`、`instance_id`、`suit`、`rank`。若某张牌没有花色/点数，使用显式 `null`，不得省略字段。

## 约束

- `instance_id` 在全部通用牌、职业牌和装备牌中全局唯一。
- `card_id` 可重复，但同一牌库中不能出现相同 `instance_id`。
- 抽牌、弃牌、装备、购买、公开出牌记录和回放命令使用 `instance_id`。
- UI 显示逻辑名称、花色和点数；调试面板显示完整实例 ID。
- 洗牌只改变实例顺序，不改变实例属性。
- 复制牌面效果复制逻辑定义时，必须根据规则生成新的合法实例或明确引用原实例；不得复制出重复 ID。

## 迁移

旧 v4 存档只有逻辑 `card_id` 时，读取器不得猜测花色/点数。应保留原文件并提示“存档需要新版规则”，由玩家开始新局。
